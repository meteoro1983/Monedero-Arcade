# Monedero Arcade

Sistema de crédito virtual para RetroBat / RetroArch: monedas, tiempo de juego y overlay en pantalla.
C# .NET 8 (WinForms/WPF).

- `MonederoArcade/` — el monedero (ver `MonederoArcade/README.md`).
- `MonederoConfig/` — el configurador.
- Compilar: `dotnet publish` (exe autocontenido de un solo archivo).
- Versión lista para usar: en **Releases**.
- Especificación: `spec_sistema_credito_arcade_actualizada.md`.
